Bases de Datos No Relacionales NoSQL · Not Only SQL

Definición

Qué es una base de datos NoSQL y en qué se diferencia del modelo relacional.
SQLTabla → filas → columnas
NoSQLDocumento / clave-valor / columnas / grafo
NoSQL

"Not Only SQL" — no solo SQL.

Base de datos no relacional

No utiliza el modelo tradicional de tablas relacionadas.

Objetivo

Almacenar y consultar información de manera flexible y escalable.

Tipos de datos que maneja

Estructurados, semiestructurados y, en algunos casos, no estructurados.

Fuente

Documentación técnica de MongoDB ↗

Características

Rasgos que distinguen a los sistemas NoSQL frente a los relacionales.
Flexibilidad

Esquema adaptable a cambios frecuentes en los requisitos.

Escalabilidad horizontal

Puede crecer agregando más servidores o nodos.

Distribución de datos

La información se reparte entre diferentes nodos o ubicaciones.

Alta disponibilidad

Uso de replicación y mecanismos de recuperación ante fallas.

Tolerancia a particiones

Sigue funcionando ante problemas de comunicación entre nodos.

Manejo de grandes volúmenes

Adecuada para escenarios de Big Data.

Rendimiento

Operaciones de lectura/escritura eficientes según el modelo y la carga.

Fuente

Ventajas de NoSQL — MongoDB ↗

Tipos

Los cuatro modelos principales de bases de datos NoSQL, con su ejemplo tecnológico y uso común.
Documental

{ usuario: "Carlos", edad: 23 }
Ejemplo: MongoDB ↗ · Uso: apps web, catálogos, perfiles.

Clave-valor

usuario123 → "Carlos"
Ejemplo: Redis · Uso: caché, sesiones, acceso rápido.

Columnas anchas

ID | Nombre | Edad | Ciudad
Ejemplo: Apache Cassandra · Uso: grandes volúmenes, sistemas distribuidos.

Grafos

Usuario A —amigo de→ Usuario B
Ejemplo: Neo4j · Uso: redes sociales, recomendaciones, relaciones.

Historia

Línea de tiempo de la evolución de NoSQL.
Bases relacionales

Uso predominante durante décadas.

Crecimiento de Internet

Aumentan los usuarios y el volumen de datos.

Principios de los 2000

Surgen arquitecturas distribuidas como Google Bigtable.

2009

Crece fuertemente el interés por NoSQL (MongoDB, CouchDB).

Década de 2010

Se expanden los distintos modelos y tecnologías NoSQL.

Actualidad

NoSQL se usa junto con bases relacionales según las necesidades del sistema.
